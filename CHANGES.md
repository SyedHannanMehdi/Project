## Planned / Proposed Changes

The following UI improvements have been identified as part of Issue #17 and will be
addressed in subsequent PRs:

- **Accessibility improvements** — improve keyboard navigation, ARIA labels, and
  colour-contrast ratios to meet WCAG 2.1 AA standards.
- **Responsive layout updates** — ensure all views render correctly on mobile,
  tablet, and desktop breakpoints.
- **Component styling refinements** — align buttons, forms, and typography with the
  updated design system.
- **User-feedback states** — add loading spinners, empty states, and error messages
  where they are currently missing.
